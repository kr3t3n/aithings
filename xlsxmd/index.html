aithings / xlsxmd

Spreadsheet to markdown.

Drop an .xlsx, .csv, or .ods. Copy a Markdown table. Formulas show the cached value Excel last saved.

The file never leaves the browser. There is no server and no account.

    Caps: 15 MB. SheetJS loads the whole workbook in this tab, so bigger files freeze the page. Old .xls, random files, and empty books fail with an error.
