aithings / nbmd

Notebook to markdown.

Drop a Jupyter .ipynb. Copy Markdown of the code and notes. Plots and cell metadata are stripped.

or paste notebook JSON

Files never leave the browser. There is no server and no account.

Caps: 50 MB. Not-a-notebook files fail with an error. Images, attachments, and cell metadata are stripped by default. Base64 is never embedded.
