aithings / docxmd

Word or LibreOffice to markdown.

Drop a Word or LibreOffice file. Copy Markdown. Old .doc files fail.

The file never leaves the browser. There is no server and no account.

Caps: 50 MB. Accepts .docx (ZIP + word/document.xml) and .odt (ZIP + content.xml). Old .doc, .pptx, and random files fail with an error.
