Strip cookies from a HAR.

Drop a .har. Download a copy with cookies, Set-Cookie, and Authorization replaced by stable placeholders.

The file never leaves the browser. There is no server and no account.

Caps: 50 MB. Same value becomes the same placeholder in one run. Chrome 130+ already strips Cookie, Set-Cookie, and Authorization on the default export — this is for unsanitized exports. Random JSON and non-HAR files fail with an error.
