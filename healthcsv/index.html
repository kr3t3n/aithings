aithings / healthcsv

Apple Health, filtered.

Drop export.xml or the Health zip. Pick types and a date range. Get a compact CSV or JSON — not the whole dump.

Files never leave the browser. There is no server and no account.

    Nothing is selected. Tick the types you want. Common ones if present: StepCount, HeartRate, BodyMass, SleepAnalysis. This will not dump the whole file.

    Caps: warn over 80 MB, refuse over 250 MB. Unknown files and ZIPs without export.xml fail with an error. Clinical / CDA / ECG files are ignored. Record and Workout only.
