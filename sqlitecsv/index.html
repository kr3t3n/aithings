aithings / sqlitecsv

SQLite to CSV.

Drop a .db or .sqlite. Tick the tables you want. Download CSV — or a zip of them.

The file never leaves the browser. There is no server and no account.

    Caps: 25 MB. sql.js loads the whole database in this tab, so bigger files freeze the page. Files that are not SQLite, empty databases, and encrypted files fail with an error. This page is not a SQL editor.
