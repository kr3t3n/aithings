aithings.online

Small tools that do one thing.

Free and open source. No signup, no accounts, nothing to install. Built by Georgi because the tool didn't exist yet.

flatten.site →

Drop in a ZIP and get back a flat file tree, or one plain-text blob with every path inlined. For pasting a whole codebase into an AI context window without losing where anything lived.

in .zip   out .txt · .zip

 makejson.online →

Turn documents, spreadsheets and source files into structured JSON. Bring your own OpenAI, Anthropic or Gemini key — the file is read in your browser and the key never touches a server here.

in .pdf · .docx · .xlsx · .csv · .zip · code   out .json

 chatmd →

Drop an official ChatGPT or Claude data-export ZIP and get one Markdown file per chat — to read, grep, or paste into another model. The ZIP is opened in your browser; nothing is uploaded.

in .zip   out .md · .zip

 tgmd →

Drop a Telegram Desktop result.json or export ZIP and get one Markdown file per chat — to read, grep, or paste into another model. The file is opened in your browser; nothing is uploaded.

in .json · .zip   out .md · .zip

 igmd →

Drop a Meta Download-your-information ZIP and get one Markdown file per Instagram or Facebook chat — to read, grep, or paste into another model. The ZIP is opened in your browser; nothing is uploaded.

in .zip   out .md · .zip

 scrub →

Drop or paste a log, snippet, .env, or dump. API keys, tokens, connection strings, emails, and IPs become stable placeholders — then copy or download and paste that into an AI. The file is opened in your browser; nothing is uploaded.

in .txt · .log · .env · paste   out .txt

 nbmd →

Drop a Jupyter .ipynb and get Markdown of the code and notes. Base64 plots, attachments, and cell metadata are stripped by default. The file is opened in your browser; nothing is uploaded.

in .ipynb   out .md
